    DEFINICIONES

    Metodología y fuentes

    Datos sintéticos deterministas hasta el 8 de noviembre de 2026. Comparación con el período anterior de igual duración. Moneda: EUR. No hay conexión a plataformas ni datos financieros reales.

    Ingresos y margen
    Ingresos = ventas propias + comisiones de afiliación, sin sumar el valor bruto de ventas afiliadas. Beneficio = ingresos − inversión publicitaria − costes de entrega. Margen = beneficio / ingresos. ROI = beneficio / inversión.
    Conversión y engagement
    Conversión general = compras / leads MQL. CTR = clics / impresiones. Conversión por impacto = compras / impresiones. Engagement = interacciones / impresiones. Compleción = compras / procesos de checkout iniciados.
    Retención y MRR
    Churn = bajas / cohorte de suscripciones renovables; retención = 1 − churn. MRR = suscripciones activas al cierre × precio mensual. Precio medio = ventas propias / compras propias.
    Calidad y satisfacción
    SQL/MQL = leads cualificados / leads. Attendance = asistentes / inscritos al evento. Pass rate = aprobados / asistentes. NPS = (% promotores − % detractores); CSAT = respuestas satisfechas / respuestas totales.
    Usuarios y alcance
    Usuarios activos deduplicados por identificador sintético. Alcance por plataforma = usuarios distintos; las audiencias de plataformas no deben sumarse sin deduplicar. CPA = inversión / compras; CPL = inversión / leads. Tiempo medio ponderado por compras.
    Comparativas
    Tasas: diferencia en puntos porcentuales. NPS: diferencia en puntos. Resto: cambio relativo. Sin base anterior se muestra «Sin base». Las mejores plataformas se calculan entre las incluidas en los filtros; los empates comparten indicador.
